# Google Fonts Palettes (PracticeBuddy)

This app now supports 4 distinct typography palettes:

1. Elegant
- Playfair Display (titles/headlines)
- Lora (body)
- IBM Plex Mono (numbers)

2. Minimalistic
- Manrope (titles/headlines/body)
- Roboto Mono (numbers)

3. Modern
- Space Grotesk (titles/headlines)
- Outfit (body)
- Space Mono (numbers)

4. Playful
- Fredoka (titles/headlines)
- Quicksand (body)
- Nunito Sans (numbers)

## Install in Xcode

1. Download each family from Google Fonts.
2. Add `.ttf` or `.otf` files to the app target in Xcode.
3. Keep target membership checked for `PracticeBuddy`.
4. Build and run.

The app auto-registers bundled fonts at launch and falls back to system fonts if a family is missing.
